    Como ligar no Zabbix e no robô de verdade
    1. Criar um usuário de API no Zabbix só com leitura e gerar um token.
    2. Um backend pequeno (Python/FastAPI) consulta a API a cada 30 s com host.get e problem.get e devolve um JSON simples para a sala.
    3. Severidade do Zabbix vira o estado do robô: Warning/Average = âmbar, High/Disaster = vermelho e vai para a sala de incidente.
    4. Quando um robô fica vermelho, o backend manda o card para o Teams (webhook) e a IA escreve o diagnóstico com base no histórico do item.
    5. O robô Foxbit já grava status, gráfico e ordens no Supabase (tabelas robo_kv e robo_trades). O backend lê essas tabelas com login e manda para a sala, sem colar nada à mão.
